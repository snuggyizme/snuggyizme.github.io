I redid the script that makes the `Label` title grow and it now automatically connects the signals. I made it take an exported `Area2D`, but I discovered that controls have the same signal that I was using from the `Area2D`: `mouse_entered` and `mouse_exited`. So the exported type is now just `Node` so you can do both `Node/CanvasItem/Node2D/CollisionObject2D/Area2D` and `Node/CanvasItem/Control/<Whatever You Like :3>`.\
