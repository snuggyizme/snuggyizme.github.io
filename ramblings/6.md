**1. Generation:**\
A pretty simple step, as I haven't really made a spectacular procedural world yet. It's just some grass, dirt and caves. We sample some noise at our *global* coordinate and sample noise there to get the height of the land:
```gdscript
var globalPosition: Vector2i = chunkPosition * Global.DIMENSION + coord
var height: float = Global.noise.get_noise_1d(globalPosition.x) # -1 to 1
```

Then we simply match the height, as well as some 2D noise (we used 1D noise for the hills as, well, I mean you *could* have 2d hills but that would kind of just be caves....) to get what block is at the current coordinate:
```gdscript
if globalPosition.y < surfaceY:
    blocks[coord] = &"_"
elif globalPosition.y == surfaceY:
    blocks[coord] = &"grass"
elif globalPosition.y < surfaceY + Global.DIRT_BUFFER_SIZE:
    blocks[coord] = &"dirt"
else:
    # If no one cares about this poor block it's gonna be rock hard
    blocks[coord] = &"stone"
    
    # 2D noise for caves
    var caveNoise: float = Global.noise.get_noise_2dv(
        globalPosition
    )
    # 2D noise for andesite
    var noiseAndesite: float = Global.noise.get_noise_2dv(
        globalPosition + Global.UNDERGROUND_NOISE_ANDESITE_OFFSET
    )
    # Check andesite first;
    if noiseAndesite < Global.UNDERGROUND_NOISE_ANDESITE_THRESHOLD:
        blocks[coord] = &"andesite"
    # Caves override andesite because I like Cave Johnson;
    if caveNoise < Global.UNDERGROUND_NOISE_CAVE_THRESHOLD:
        blocks[coord] = &"_"
```

One thing of note in this stage, however, is that because I have an autotiling system that matches the right tile sprite to show where the air is and where the solid stuff is, we have to make sure that works along chunk borders. My solution to this was pretty silly but it works wonders. Instead of looping over the size of the chunk, we loop from -1 to the size + 1, and then, after we generate the current tile in the loop we check if thats solid and if it's on the outer ring of tiles, and if thats true we replace it with an invisible block with no collision:
```gdscript
for x in range(-1, Global.DIMENSION.x + 1):
    for y in range(-1, Global.DIMENSION.y + 1):

        # All of the code we had above.....

        if (
            blocks[coord] != &"_" and
            (
                x < 0 or
                y < 0 or
                x >= Global.DIMENSION.x or
                y >= Global.DIMENSION.y
            )
        ):
            blocks[coord] = &"_chunkConnect"
```

**2. Terrain Mask**\
Now we're out of the territory of *generation* and into the *update* function. This stuff has even more reason to be lightnight fast, as this code runs every time the chunk changes, from mining, bombs, being loaded, etc.

First up: We wait two process frames.\
I'm sorry I'm sorry please don't execute me (Twas Justine's idea I swear! I swear!). I had a swarm of errors (maybe 5 or 6 per frame?) coming in with bad descriptions and no traces back to my code, so we assumed something was fucked up loading and just waited.

Next, we initialize a 1D array of terrain cells. We use a 1D array because ***GODOT SAID SO***. *Okay?*
```gdscript
var terrainCells: Array[Vector2i] = []
terrainCells.resize((Global.DIMENSION.x + 2) * (Global.DIMENSION.y + 2))
var terrainCellsSize := 0
```

We then iterate over every block (including our magical chunk-border blocks we made in the last step) and, if the block is not air, we add it to an array of block coordinates to form a binary mask of the world:
```gdscript
for x in range(-1, Global.DIMENSION.x + 1):
    for y in range(-1, Global.DIMENSION.y + 1):       # So evil ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓!
        if counter >= Global.TILES_PER_FRAME and Global.DO_EVIL_TILES_PER_FRAME:
            counter = 0
            frameCount += 1
            await get_tree().process_frame
        
        var coord := Vector2i(x, y)
        
        if blocks[coord] == &"_":
            continue
        
        terrainCells[terrainCellsSize] = coord
        terrainCellsSize += 1
        
        counter += 1
```

..which can then be passed directly into the gates of hell:
```gdscript
tileMap.set_cells_terrain_connect(terrainCells, 0, 0)
```

**4. Tiles**
I love this solution I came up with to make my autotiling dream work, even if it didn't end up being the most performant thing. Here's where it all comes together. So far we have a mask of the world, but it's currently all this Hideous Pink Test Block™:\
![IMG - Men kissing. Ooo now you wanna see it don't you](/assets/imgs/5.png)

The texture atlases for each block have the same layout and are all in the same TileSet resource, which stores atlases by index. So it's simple, we used the steps above to get two sets of data:\
1. What block/tile type is at our current chunk coordinate?
2. What is the atlas coordinate of the tile at our current chunk coordinate?

And we can combine them by getting the source atlas index property from the block and then setting the cell to have the same atlas coordinate but on the atlas specified by the block. I worded that horribly and I don't care. Cope. Or read:
```gdscript
for x in range(-1, Global.DIMENSION.x + 1):
    for y in range(-1, Global.DIMENSION.y + 1):
        var coord := Vector2i(x, y) 
        var coordFromCell := tileMap.get_cell_atlas_coords(coord)
        
        if coordFromCell == emptyCoord:
            continue
        
        var block: Block = Global.blockDict.get(
            blocks[coord], fallbackBlock
        )
        
        tileMap.set_cell(coord, block.sourceAtlas, coordFromCell)
```
